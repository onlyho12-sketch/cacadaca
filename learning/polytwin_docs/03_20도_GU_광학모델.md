# 03. 20° GU Proxy와 RTX 광학모델

## 1. 목적

논문에 제시된 자동차 20° Gloss 값을 수치 앵커로 사용하고, Isaac Sim의 상대 정반사 측정과
표면상태 모델을 결합하여 위치별 `predicted_20deg_gu_literature_proxy`를 계산한다.

실제 Gloss Meter 보정은 수행하지 않는다. 이 문서의 GU는 디지털 트윈 결과척도다.

## 2. 논문 GU 앵커

```yaml
defective_anchor_gu: 25.0
good_refinish_anchor_gu: 78.0
high_gloss_vehicle_anchor_gu: 89.0
target_gu: 70.0
```

근거:

- 결함 보수도장 시편 약 21.1~29.7 GU
- 양호한 보수도장 시편 약 75.8~79.7 GU
- 상용 신차 전체 평균 약 88.8 GU
- 저자 제안 평균 20° Gloss 목표 `>70 GU`

## 3. 국소 20° 측정기하

측정점 `p`, 외향 단위법선 `n`, 접평면의 측정방향 단위벡터 `t`를 정의한다.

```python
n = normalize(surface_normal)
t0 = path_tangent - dot(path_tangent, n) * n
t = normalize(t0)
b = normalize(cross(n, t))
```

경로 접선이 불안정하거나 0에 가까우면 이전 valid tangent 또는 주곡률 방향을 사용한다.

20°를 radian으로 변환한다.

```python
theta = radians(20.0)
```

광원과 카메라를 법선 기준 대칭으로 배치한다.

```python
source_direction_from_point = cos(theta) * n + sin(theta) * t
camera_direction_from_point = cos(theta) * n - sin(theta) * t

source_position = p + source_distance * source_direction_from_point
camera_position = p + camera_distance * camera_direction_from_point
```

광원은 `p`를 향하고 카메라도 `p`를 바라본다. 입사벡터와 반사벡터가 법선 양쪽에서 각각
20°가 되도록 배치한다.

## 4. 곡면 측정점 생성

평면 5×5에서는 균일 UV grid를 사용했다. 곡면에서는 표면경로의 arc length 기준으로 측정점을
배치한다.

```text
surface mesh/point cloud
→ 검사 대상 patch 분할
→ arc-length 일정 간격 경로 생성
→ 각 경로점 위치·법선·접선·곡률 계산
→ Local 20° source/camera pose 계산
→ RTX 측정
→ 원래 surface id/UV에 결과 저장
```

각 결과:

```python
GlossSample = {
    "sample_id": ...,
    "surface_id": ...,
    "position_world_m": [x, y, z],
    "normal_world": [nx, ny, nz],
    "tangent_world": [tx, ty, tz],
    "principal_curvature_1_m": k1,
    "principal_curvature_2_m": k2,
    "relative_specular_response": q_optical,
    "predicted_20deg_gu_literature_proxy": gu_proxy,
}
```

## 5. Curvature와 footprint 유효성

Gloss 측정은 한 점이 아니라 유한한 footprint를 본다. footprint 안에서 법선이 크게 달라지면
중심법선 하나로 20° 조건을 만족한다고 볼 수 없다.

```python
normal_spread_deg = percentile(
    angle(neighbor_normals, center_normal),
    95,
)
```

`normal_spread_deg`가 config 한계를 넘으면:

1. 측정 footprint를 줄인다.
2. patch를 더 작게 분할한다.
3. 그래도 크면 `curvature_invalid`로 표시한다.

이 한계는 `PT-DESIGN`이고 로그에 기록한다.

## 6. RTX 상대 광택 측정

고정해야 하는 항목:

```text
renderer와 sample count
exposure, tone mapping, white balance
source shape, intensity, spectrum/color
camera aperture/focal length/resolution
source/camera distance
measurement ROI
material base color/IOR/metallic
clearcoat layer와 roughness mapping
background와 주변광
```

정반사 ROI 신호와 background 신호를 분리한다.

```python
signal = mean_luminance(specular_roi) - mean_luminance(background_roi)
relative_specular_response = clip(
    signal / pristine_reference_signal,
    0.0,
    relative_response_max,
)
```

Path Tracing은 최종 측정·평가에 사용하고 GUI 확인은 RTX Real-Time을 사용한다.

## 7. 표면상태 품질항

### 7.1 Roughness 품질

```python
q_ra = exp(
    -max(0.0, ra_um - ra_reference_um) / ra_decay_scale_um
)
```

### 7.2 Scratch 품질

```python
q_scratch = 1.0 - clip(
    residual_scratch_metric_um / max(initial_scratch_metric_um, epsilon),
    0.0,
    1.0,
)
```

### 7.3 균일도 품질

```python
q_uniformity = exp(
    -std(local_quality_or_removal) / uniformity_decay_scale
)
```

### 7.4 Clearcoat 보전 품질

```python
q_clearcoat = clip(
    (minimum_remaining_clearcoat_um - failure_limit_um)
    / (initial_clearcoat_mean_um - failure_limit_um),
    0.0,
    1.0,
)
```

## 8. GU proxy 결합식

각 품질항을 geometric combination으로 결합하면 한 항의 심한 결함이 평균에 숨는 것을 줄일 수
있다.

```python
q_total = (
    q_ra ** w_ra
    * q_scratch ** w_scratch
    * q_uniformity ** w_uniformity
    * q_clearcoat ** w_clearcoat
    * q_optical ** w_optical
) ** (1.0 / sum(weights))
```

GU 변환:

```python
predicted_20deg_gu_literature_proxy = clip(
    defective_anchor_gu
    + (good_refinish_anchor_gu - defective_anchor_gu) * q_total,
    0.0,
    100.0,
)
```

고광택 신차 profile을 별도 선택하는 경우 upper anchor를 89 GU로 변경한다. 한 run 안에서 anchor를
바꾸지 않는다.

## 9. 현재 상대 광택 결과의 예시 변환

현재 5×5 distributed roughness 시험의 비정상 셀 평균 상대광택:

```text
Before: 0.2180
After : 0.8815
```

단순 optical-only mapping 예시:

```python
GU = 25 + relative_gloss * (78 - 25)
```

```text
Before ≈ 36.6 simulation GU proxy
After  ≈ 71.7 simulation GU proxy
```

이 계산은 모델 동작예시다. 최종모델에서는 Roughness, Scratch, 균일도, Clearcoat 항을 함께
사용하고 model version을 기록한다.

## 10. 판정

```yaml
gu_proxy_bands:
  target_pass: ">= 70"
  partial: "60 <= GU < 70"
  low: "30 <= GU < 60"
  severe_defect: "GU < 30"
```

최종 성공은 평균만으로 판정하지 않는다.

```python
gloss_pass = (
    mean_gu >= 70.0
    and percentile_10_gu >= gu_low_percentile_limit
    and std_gu <= gu_uniformity_limit
    and minimum_gu >= gu_minimum_limit
)
```

`gu_low_percentile_limit`, `gu_uniformity_limit`, `gu_minimum_limit`은 `PT-DESIGN` config다.

## 12. 단위시험

1. 평면 법선 `+Z`, tangent `+X`에서 광원·카메라가 법선 양쪽 20°인지 확인.
2. 임의 회전된 평면에서도 각도가 20°로 유지되는지 확인.
3. 법선 flip 연속성 검사.
4. pristine response에서 `q_optical≈1`인지 확인.
5. roughness/scratch 증가 시 GU proxy가 감소.
6. Clearcoat 과다 제거 시 GU만 높아도 전체 성공이 실패.
7. 같은 표면을 다른 월드 pose로 회전해도 국소 GU 결과가 동일.
8. Before 0.218/After 0.8815 예시 mapping 회귀시험.
