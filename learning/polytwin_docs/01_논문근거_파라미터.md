# 01. 논문 근거와 파라미터

## 1. 목적

이 문서는 디지털 트윈에 입력할 모든 수치를 논문 직접값, 논문 기반 파생값, PolyTwin 설계값으로
분리한다. 서로 다른 재료·공구 논문의 결과는 민감도와 탐색범위의 근거로 사용하고, 자동차
Clearcoat 직접값처럼 표현하지 않는다.

## 2. 자동차 Clearcoat와 초기 표면

### 2.1 Clearcoat 두께

Alsoufi et al.은 자동차 도장시스템의 Clearcoat를 약 `30~50 μm`로 설명한다. 다른 자동차
코팅 문헌에서는 대표적으로 `40~50 μm`가 제시된다.

```yaml
initial_clearcoat_thickness_um:
  distribution: uniform
  min: 40.0
  max: 50.0
  tag: L-DERIVED
  reason: 자동차 문헌 범위 안의 PolyTwin 초기분포
```

### 2.2 정상 표면 Ra

Toyota 2016 흰색 자동차 Clearcoat의 외부 노출 전 측정값:

```text
Group 1: 0.078 ± 0.011 μm
Group 2: 0.083 ± 0.009 μm
```

PolyTwin 정상 목표:

```yaml
ra_target_um:
  best_min: 0.075
  best_max: 0.095
  pass_min: 0.070
  pass_max: 0.100
  tag: PT-DESIGN
  anchor: Toyota 논문 약 0.08 μm
```

### 2.3 Scratch 깊이

자동차 Clearcoat scratch 연구의 대표 범위:

```yaml
initial_scratch_depth_um:
  min: 0.05
  max: 2.0
  tag: L-DIRECT
```

Scratch의 밀도, 길이, 폭, 방향은 논문 직접분포가 없으므로 `PT-DESIGN`으로 생성한다.

### 2.4 Rz

`Rz=Ra×4~6`은 기계가공 표면에서 사용되는 경험적 관계이며 드문 깊은 Scratch를 가진 도장면의
정답이 아니다. 초기 synthetic 표면 생성 확인용 범위로만 사용하고 최종 Rz는 Height Map에서
직접 계산한다.

```text
Height Map → Ra 직접 계산
Height Map → Rz 직접 계산
Height Map → maximum residual scratch 직접 계산
```

## 3. 실제 자동차 폴리싱 집계 기준점

자동차 표면 연마 비교 논문의 일반 폴리싱 공정:

| 단계 | 패드·compound | 속도 | 시간 |
|---|---|---:|---:|
| 1 | 5 inch wool, #2000 | 3500~4500 OPM | 15 min |
| 2 | 5 inch foam, #3000 | 3000~3500 OPM | 10 min |
| 3 | foam, finish glaze | 2500~3000 OPM | 5 min |

전체 공정 결과:

```text
도막 두께: 약 95 → 92 μm
감소량   : 약 3 μm
광도     : 약 40 → 49 Lux
```

- `3 μm`는 전체 3단계 공정의 집계 제거 기준점으로 사용한다.
- 논문이 단계별 제거량을 제공하지 않으므로 단계별 분배는 `PT-DESIGN`이다.
- Force와 Feed가 제시되지 않아 이 논문만으로 `F/RPM/Feed→Removal`을 식별할 수 없다.
- OPM은 DA 폴리셔의 궤도운동이며 회전식 스핀들의 RPM과 동일하지 않다.
- Lux는 광도이며 GU가 아니다. GU 모델의 수치 앵커로 사용하지 않는다.
- 세터늄 공정의 두께 `97→99 μm`는 코팅막 형성으로 증가한 값이므로 연마 제거식에서 제외한다.

## 4. Force/RPM/Feed 민감도 근거

### 4.1 NAK80 금형강

Shi et al.의 로봇 폴리싱 조건:

```text
P180: 20 N, 5000 rpm, 5 mm/s → Ra 0.08 μm
P400: 10 N, 4000 rpm, 5 mm/s → Ra 0.044 μm
P800: 20 N, 5000 rpm, 5 mm/s
```

재료가 NAK80 금형강이므로 결과 Ra와 제거계수를 자동차 Clearcoat에 직접 이식하지 않는다.
Force/RPM/Feed가 표면결과에 영향을 주는 방향성과 normalized sensitivity의 후보로 사용한다.

### 4.2 항공기 프라이머

Force별 결과:

```text
5 N  → Ra 1.653 μm
15 N → Ra 1.350 μm
20 N → Ra 1.606 μm
```

Force 증가가 항상 표면품질을 개선하지 않음을 보여준다. PolyTwin 모델에는 높은 Force에서
효율이 포화되거나 열·과연마 위험이 증가하는 비단조 항을 포함한다.

### 4.3 Feed Speed

Denkena et al.은 황동 평면시편에서 Feed를 `50~500 mm/min`으로 사용했다.

```text
50 mm/min  = 0.833 mm/s
500 mm/min = 8.333 mm/s
```

PolyTwin 레시피 탐색 후보:

```yaml
feed_speed_mm_s:
  min: 1.0
  max: 8.0
  tag: L-DERIVED
```

### 4.4 자동차 폴리싱 RPM 직접값

Kakinuma et al.과 Oba et al.의 자동차 폴리싱 연구에서 `5000 min⁻¹`가 사용됐다.

```yaml
rpm:
  automotive_anchor: 5000
  synthetic_search_min: 3000
  synthetic_search_max: 6000
  anchor_tag: L-DIRECT
  range_tag: PT-DESIGN
```

현재 v5 코드는 `314.16 rad/s ≈ 3000 rpm`으로 패드를 시각·물리 회전시킨다. 품질효과는
본 문서 세트의 커스텀 표면상태 모델이 담당한다.

## 5. Contact Force 적용

논문 기반 후보는 `5~20 N`이지만 현재 v5 제어기는 다음 값을 사용한다.

```text
상단 평탄면 목표: 8.0 N
상단 급경사 목표: 5.0 N
측면 평탄면 목표: 6.0 N
측면 급경사 목표: 3.5 N
상단 하드 제한  : 14.0 N
측면 하드 제한  : 6.0 N
```

따라서 Isaac Lab 로봇 행동범위는 현재 안전 계층과 일치시킨다. `5~20 N` 전체는 BO의 synthetic
공정 연구 후보로만 둘 수 있으며, 현재 로봇 안전 계층과 결합할 때는 feasible domain을
`region hard limit`으로 잘라낸다.

```python
bo_force_domain = intersection(
    literature_candidate_domain,
    robot_region_safe_domain,
)
```

## 6. Step-over

정의:

```python
step_over_spacing_ratio = path_center_spacing / pad_diameter
overlap_ratio = 1.0 - step_over_spacing_ratio
```

현재 110 mm 패드와 v5 `rail/full` 경로:

| 구역 | 중심간격 | spacing ratio | overlap ratio |
|---|---:|---:|---:|
| 상단 | 90 mm | 0.818 | 0.182 |
| 측면 | 50 mm | 0.455 | 0.545 |

기존 4대 고정 `multi` 모드의 상단 30 mm와 혼용하지 않는다. 모든 결과에 mode와 실제 중심간격을
기록한다.

## 7. 20° Gloss 직접 앵커

Coatings 2021 연구:

```text
B-segment 신차 전체 평균 20° Gloss : 67.7 GU
상용차 신차 전체 평균 20° Gloss    : 88.8 GU
양호한 보수도장 시편                : 약 75.8~79.7 GU
결함 보수도장 시편                  : 약 21.1~29.7 GU
저자 제안 평균 20° Gloss 목표        : >70 GU
```

또한 해당 논문은 60° 측정값이 70 GU보다 높은 고광택 표면에 20° geometry를 사용하는 절차를
설명한다. `60°에서 70 GU`인 각도선택 기준과 `평균 20° Gloss >70 GU`인 저자 결론을 구분한다.

PolyTwin 설정:

```yaml
gu_proxy:
  defective_anchor_gu: 25.0
  good_refinish_anchor_gu: 78.0
  high_gloss_anchor_gu: 89.0
  final_target_gu: 70.0
  tag: L-DERIVED
```

`25/78/89`는 논문 표의 여러 값을 대표값으로 축약한 `L-DERIVED` 앵커다.

## 8. 근거와 가정의 모델 결합 원칙

```text
자동차 논문 직접값
  → 두께·Scratch·GU·집계 제거량의 절대 앵커

타 재료 폴리싱 논문
  → Force/RPM/Feed 민감도의 방향과 후보 범위

PolyTwin 설계값
  → 서로 다른 논문 앵커를 연결하는 지수·가중치·포화함수

디지털 트윈 출력
  → SYNTHETIC 태그를 가진 위치별 품질상태
```
