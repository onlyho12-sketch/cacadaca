# 02. 표면상태와 폴리싱 물리모델

## 1. 목적

Isaac Lab이 계산한 패드 접촉상태를 위치별 Clearcoat 품질 변화로 변환한다. 이 모델은 PhysX가
기본 제공하는 재료 마모기능이 아니라 PolyTwin이 추가하는 커스텀 상태 전이모델이다.

```text
PhysX: 로봇·패드 접촉력, 위치, 자세, 속도
                     ↓
PolyTwin Polishing Model
                     ↓
Height/Scratch/Removal/Clearcoat/Ra/Rz/GU 상태
```

## 2. 표면 표현

각 작업 patch는 국소 `u-v` 좌표와 다음 상태맵을 가진다.

```python
SurfaceState = {
    "nominal_surface_xyz_m": float[N, M, 3],
    "normal_xyz": float[N, M, 3],
    "micro_height_um": float[N, M],
    "initial_scratch_depth_um": float[N, M],
    "residual_scratch_depth_um": float[N, M],
    "cumulative_removal_um": float[N, M],
    "clearcoat_remaining_um": float[N, M],
    "dwell_time_s": float[N, M],
    "pass_count": int[N, M],
    "peak_contact_pressure_proxy": float[N, M],
    "heat_risk_proxy": float[N, M],
    "healthy_mask": bool[N, M],
    "defect_mask": bool[N, M],
}
```

`nominal_surface_xyz_m`는 차체의 거시형상이고 `micro_height_um`는 Ra/Rz/Scratch를 계산하는
미세형상이다. 단위를 섞지 않는다.

## 3. 초기 표면 생성

### 3.1 Clearcoat

```python
clearcoat_remaining_um[:] = uniform(40.0, 50.0)
```

한 patch 안의 두께는 공간적으로 완전히 독립 난수가 아니라 저주파 correlated field로 만든다.

### 3.2 정상 Roughness

정상 표면의 target Ra를 약 `0.08 μm`로 두고 band-limited noise를 생성한다.

```text
white noise
→ spatial low-pass/band-pass
→ mean 제거
→ 목표 Ra가 되도록 amplitude scale
```

```python
micro_height_um *= target_ra_um / mean(abs(micro_height_um - mean(micro_height_um)))
```

### 3.3 Scratch

Scratch는 국소 접평면에서 polyline 또는 spline으로 생성한다.

```python
scratch = {
    "centerline_uv": ...,
    "depth_um": uniform(0.05, 2.0),
    "width_m": PT_DESIGN,
    "length_m": PT_DESIGN,
    "profile": "gaussian_or_v_groove",
}
```

Gaussian groove 예시:

```python
scratch_height_um = -depth_um * exp(-(distance_to_centerline_m / width_scale_m) ** 2)
micro_height_um += scratch_height_um
```

Scratch 밀도·폭·길이는 논문 직접분포가 아니므로 config에 `PT-DESIGN`으로 기록한다.

## 4. 패드 접촉 footprint

패드 중심을 surface UV로 투영하고 패드 반경 `R` 안의 셀에 normalized weight를 계산한다.

```python
rho = distance_uv / pad_radius_m
raw_weight = exp(-0.5 * (rho / footprint_sigma_ratio) ** 2)
raw_weight[rho > 1.0] = 0.0
weight = raw_weight / sum(raw_weight)
```

경사진 패드와 곡면에서는 원형 footprint를 접평면에 투영한 ellipse와 실제 접촉셀 비율로
수정한다.

```text
effective_contact_area_m2
contact_area_ratio
normal_alignment = max(0, dot(pad_normal, surface_normal))
```

패드 전체 원면적이 아니라 현재 접촉한 유효면적을 압력 계산에 사용한다.

## 5. 접촉압력과 상대속도

평균 압력:

```python
pressure_pa = contact_force_n / max(effective_contact_area_m2, area_epsilon)
```

회전식 패드의 대표 접선속도:

```python
omega_rad_s = rpm * 2.0 * pi / 60.0
effective_radius_m = effective_radius_ratio * pad_radius_m
spin_speed_m_s = omega_rad_s * effective_radius_m
relative_speed_m_s = sqrt(spin_speed_m_s**2 + feed_speed_m_s**2)
```

DA 폴리셔 논문의 OPM은 위 RPM 식에 직접 넣지 않는다. 자동차 논문의 OPM 공정은 집계 제거량
앵커로만 사용하고 PolyTwin 회전식 모델의 reference rpm은 별도 `PT-DESIGN`이다.

## 6. 기본 제거식

Preston 형태를 기반으로 한 literature-informed synthetic 식:

```python
delta_removal_um = (
    k_literature_synthetic
    * pressure_pa
    * relative_speed_m_s
    * quality_dt_s
    * footprint_weight
    * compound_factor
    * pad_factor
    * alignment_factor
    * force_efficiency
    * heat_efficiency
)
```

각 항:

```python
alignment_factor = clip(normal_alignment, 0.0, 1.0) ** alignment_exponent

force_ratio = contact_force_n / reference_force_n
force_efficiency = force_ratio ** force_exponent

# 높은 Force에서 무한히 좋아지지 않도록 포화·과연마 반영
force_efficiency /= 1.0 + force_saturation_gain * max(0, force_ratio - 1.0) ** 2
```

`force_exponent`, `alignment_exponent`, `force_saturation_gain`, compound/pad factor는
`PT-DESIGN`이며 model config와 결과에 저장한다.

Feed는 별도의 `1/feed` 항으로 다시 곱하지 않는다. 패드가 빠르게 이동할수록 한 셀에 머무는
physics step 수와 dwell이 자연스럽게 감소하기 때문이다. Feed 역수를 또 곱하면 효과를 이중
계산한다.

## 7. 제거계수의 논문 기반 내부 정규화

자동차 일반 폴리싱 논문의 전체 제거량 약 `3 μm`를 절대 앵커로 사용한다. 논문에는 Force,
Feed 및 실제 작업면적이 없으므로 다음 reference simulation을 PolyTwin이 정의한다.

```yaml
reference_simulation:
  patch_size_m: [0.20, 0.20]
  pad_diameter_m: 0.11
  target_force_n: 8.0
  feed_speed_mm_s: 5.0
  rpm_schedule: [4000, 3250, 2750]
  stage_time_ratio: [0.50, 0.333333, 0.166667]
  path_type: raster
  step_over_spacing_ratio: PT_DESIGN
  target_mean_removal_um: 3.0
```

위 reference recipe는 논문의 15/10/5분 시간비와 OPM 중심값을 회전식 RPM proxy로 옮긴
`L-DERIVED + PT-DESIGN` 구성이다. 실제 논문 조건과 동일하다고 표현하지 않는다.

계수 산정:

```python
unit_model = run_reference_simulation(k_literature_synthetic=1.0)
k_literature_synthetic = (
    3.0 / mean(unit_model.cumulative_removal_um)
)
```

이렇게 하면 reference simulation의 평균 제거량이 정확히 `3 μm`가 된다. model version이
바뀌면 이 정규화를 다시 수행하고 coefficient와 reference config hash를 저장한다.

## 8. 미세형상 갱신

단순히 모든 셀 높이를 동일하게 낮추면 Ra와 Scratch가 변하지 않는다. 폴리싱은 돌출부를 더
빠르게 제거하는 smoothing 항이 필요하다.

국소 평균과 표준편차:

```python
local_mean = weighted_local_mean(micro_height_um, pad_footprint)
local_std = weighted_local_std(micro_height_um, pad_footprint)
z_score = (micro_height_um - local_mean) / max(local_std, height_epsilon)
peak_selectivity = sigmoid(peak_selectivity_gain * z_score)
```

높이 갱신:

```python
local_material_removal_um = delta_removal_um * (
    base_removal_fraction
    + selective_removal_fraction * peak_selectivity
)

micro_height_um -= local_material_removal_um
cumulative_removal_um += local_material_removal_um
clearcoat_remaining_um -= local_material_removal_um
```

높은 돌출부가 더 많이 낮아지고 Scratch valley 주변 표면이 내려가면서 상대 Scratch 깊이가
감소한다.

```python
residual_scratch_depth_um = calculate_valley_depth_from_local_reference(
    micro_height_um,
    scratch_centerline,
)
```

`base_removal_fraction + selective_removal_fraction`의 정규화 규칙을 명시하여 제거량을 이중
합산하지 않는다.

## 9. Ra와 Rz 계산

평가 patch에서 nominal shape와 저주파 차체곡률을 제거한 residual profile `z`를 사용한다.

```python
z = micro_height_um - fitted_local_nominal_surface_um
ra_um = mean(abs(z - mean(z)))
```

PolyTwin Rz는 동일 evaluation line/patch에서 높은 peak 5개와 깊은 valley 5개의 대표차를
사용하는 프로젝트 정의로 계산하고 method id를 저장한다.

```python
rz_um = mean(top_five_peaks) - mean(bottom_five_valleys)
rz_method = "polytwin_rz_5peak_5valley_v1"
```

Ra/Rz 계산 window 크기, detrending 방법, sampling spacing을 config에 기록한다.

## 10. Dwell, Pass, Coverage

```python
active = footprint_weight > footprint_active_threshold
dwell_time_s[active] += quality_dt_s
```

Pass Count는 같은 접촉 중 매 step 증가시키지 않는다. 셀이 `inactive→active`로 전환될 때 새
pass로 판정하며 minimum off-time 또는 경로 line id로 debounce한다.

```python
if became_active_after_valid_gap(cell):
    pass_count[cell] += 1
```

Coverage:

```python
worked = cumulative_removal_um >= minimum_effective_removal_um
coverage_ratio = worked.sum() / target_mask.sum()
delta_coverage = coverage_ratio_t - coverage_ratio_t_minus_1
```

## 11. Heat-risk proxy

실제 °C 모델이 아니라 위치별 열위험 상태를 계산한다.

```python
heat_input = heat_gain * pressure_pa * relative_speed_m_s
heat_decay = heat_risk_proxy / cooling_time_constant_s

heat_risk_proxy += (
    heat_input * quality_dt_s
    - heat_decay * quality_dt_s
)
heat_risk_proxy = clip(heat_risk_proxy, 0.0, heat_proxy_max)
```

`heat_risk_proxy`는 온도 단위를 사용하지 않는다. 실패조건 이름도
`heat_proxy_limit_exceeded`로 기록한다.

## 12. 정상부 과다 제거와 Clearcoat 실패

```python
healthy_overremoval_um = maximum(
    0.0,
    cumulative_removal_um[healthy_mask] - healthy_allowance_um,
)

clearcoat_failure = any(
    clearcoat_remaining_um < clearcoat_safety_limit_um
)
```

Clearcoat 안전한계와 정상부 허용 제거량은 `PT-DESIGN`이다. 논문 직접규격으로 표현하지 않는다.

## 13. 모델 업데이트 주기

PhysX가 60 Hz이고 PPO가 20 Hz여도 품질맵을 어느 주기로 갱신하는지 명확히 한다.

권장 순서:

```text
physics substep마다 force/pose 누적
→ PPO control step 끝에서 평균/peak 계산
→ quality model 1회 갱신
→ reward와 observation 계산
```

`quality_dt_s`는 실제 누적 physics 시간과 같아야 한다.

## 15. 단위시험

1. Force=0 또는 contact=false이면 제거량=0.
2. 동일 조건에서 dt를 절반으로 하고 step을 두 배로 하면 총 제거량이 거의 동일.
3. RPM 증가 시 reference domain 안에서 제거율 증가.
4. Feed 증가 시 동일 경로셀의 dwell과 제거량 감소.
5. 정상부를 반복하면 과다제거 penalty 증가.
6. 돌출부가 valley보다 빠르게 제거되어 Ra가 감소.
7. reference simulation 평균 제거량=3 μm.
8. Clearcoat Map에서 제거된 양과 cumulative removal의 물질수지가 일치.
9. 같은 seed/config로 동일 결과 재현.
10. map 해상도를 바꿔도 면적 정규화 후 평균결과가 급변하지 않음.
