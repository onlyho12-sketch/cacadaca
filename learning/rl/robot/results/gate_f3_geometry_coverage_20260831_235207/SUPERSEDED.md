# Superseded F3 diagnostic

This first CPU screen exposed a sign mismatch between the imported
cylinder/sphere height gradients and their reported normals.  For example, the
R=0.60 m cylinder produced an impossible 21.52 mm local tangent-plane deviation
over the 55 mm pad radius.

The directory is preserved without deleting or overwriting its raw CSV/JSON.
It is not valid evidence for F4 candidate selection.  Gate F3 was rerun in a
new timestamped directory after making the isolated Gate F geometry normals
consistent with numerical derivatives of the declared height field.
