# Gate F5 corrected-xyzw bounded probe

This is a deliberately incomplete 300-control-step sphere probe, not a Gate
result.  It verified the corrected Isaac Lab `xyzw` target composition and the
actual pad-body local `+Y` outward axis before full runs.  Over the final 100
rows, normal-alignment error had mean 0.389 degrees and p95 0.402 degrees.
Only `partial_force_trace.csv` is evidence; this directory is excluded from
final F5 aggregation.
