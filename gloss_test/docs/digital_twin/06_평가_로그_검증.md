# 06. 평가, 로그, 검증

## 1. 검증의 의미

실제 실험을 수행하지 않으므로 본 프로젝트 검증은 다음을 의미한다.

```text
논문값 추적 가능성
단위·수식·물질수지 일관성
reference anchor 재현
코드 단위·통합 회귀시험
학습/평가 형상 분리
baseline 대비 PPO 성능
manual recipe 대비 BO 성능
RTX 시각화와 품질맵 방향 일치
```

실물 정확도 검증을 의미하지 않는다.

## 2. 검증 계층

### V0. 문서·설정

- 모든 수치에 `L-DIRECT/L-DERIVED/PT-DESIGN/SYNTHETIC` 태그
- 단위 포함 변수명
- model/config/git version 저장
- 구버전 문서와 현재 문서 혼용 금지

### V1. 수식 단위시험

- Force=0이면 제거=0
- 제거량과 Clearcoat 감소 물질수지 일치
- dt 분할 불변성
- RPM/pressure 민감도 방향
- Feed에 따른 dwell 변화
- Height Map 기반 Ra/Rz 재계산
- GU anchor mapping
- Local 20° 기하

### V2. Reference regression

- reference polishing simulation 평균 제거량 `3 μm`
- 결함 anchor `25 GU`
- 양호 보수도장 anchor `78 GU`
- 고광택 profile `89 GU`
- current relative gloss before/after 예시 `36.6/71.7 proxy GU`

### V3. 환경 통합

- Isaac Lab reset 재현
- action=0 baseline과 v5 비교
- 품질맵 update와 reward 동기화
- 안전 종료 reason 검증
- map indexing/좌표변환 검증

### V4. RL 평가

- 평면 제어
- 곡면 일반화
- 미학습 synthetic surface
- 미학습 실제 object mesh
- reward hacking/ablation

### V5. BO 평가

- BO surrogate prediction error
- constrained candidate selection
- manual recipe 대비 최적 feasible score
- Test surface에서 recipe robustness

## 5. 성공 판정

평균 GU 하나로 판정하지 않는다.

```python
quality_success = (
    mean_gu_proxy >= 70.0
    and p10_gu_proxy >= config.gu_p10_limit
    and std_gu_proxy <= config.gu_std_limit
    and final_ra_um within config.ra_pass_band
    and final_rz_um <= config.rz_limit
    and residual_scratch_um <= config.scratch_limit
    and min_clearcoat_um >= config.clearcoat_safety_limit
    and healthy_overremoval_um <= config.healthy_overremoval_limit
)

control_success = (
    force_rmse <= config.force_rmse_limit
    and force_peak <= config.region_force_hard_limit
    and path_p95 <= config.path_p95_limit
    and contact_ratio >= config.contact_ratio_min
    and collision_count == 0
)

episode_success = quality_success and control_success and path_complete
```

GU 이외 limit은 `PT-DESIGN`이며 resolved config에 기록한다.

## 6. Train/Validation/Test

```text
Train          : 정책 gradient update에 사용
Validation     : checkpoint와 hyperparameter 선택
Test synthetic : 미학습 곡률/freeform/transition
Test object    : 미학습 자동차·물체 mesh patch
```

surface id, generator seed, curvature bin이 split 사이에 중복되지 않는지 자동검사한다.

## 7. Baseline

```text
Baseline A: 현재 v5 standalone controller
Baseline B: Isaac Lab port, residual action=0
Candidate : Isaac Lab + PPO residual
```

먼저 A/B 차이를 확인한 뒤 B/C를 비교한다.

- PPO residual 제거
- curvature observation 제거
- local quality map 제거
- force derivative reward 제거

- healthy overremoval penalty 제거
