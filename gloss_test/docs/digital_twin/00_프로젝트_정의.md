# 00. 프로젝트 정의

## 1. 목표

PolyTwin은 Isaac Lab 내부에 자동차 Clearcoat 폴리싱 과정을 코드로 구현한다. 로봇 패드가
표면을 지나갈 때 접촉력, RPM, 이동속도, 체류시간, Pass Count 및 Step-over에 따라 위치별
표면 상태가 변화하고, 그 결과로 제거량·Ra·Rz·잔존 Scratch·잔존 Clearcoat·20° GU proxy가
계산되는 논문 기반 디지털 트윈을 구축한다.

정책은 자동차 한 대의 고정 좌표를 암기하지 않는다. 평면, 볼록면, 오목면, 구면, 원통면,
곡률 전이 및 자유곡면에서 학습하고, 새 mesh 또는 point cloud가 입력되면 국소 표면 법선과
곡률을 사용해 동일 정책을 적용한다.

## 2. 최종 출력

한 에피소드가 끝나면 다음을 출력한다.

```text
before/after height map
before/after scratch depth map
cumulative removal map
remaining clearcoat map
before/after Ra map
before/after Rz map
before/after predicted 20° GU proxy map
dwell time map
pass count map
contact force map
temperature-risk proxy map
quality pass/fail summary
```

## 3. 성공조건 구조

```python
success = (
    predicted_20deg_gu_literature_proxy >= gu_target
    and predicted_ra_um within ra_target_band
    and predicted_rz_um <= rz_limit
    and residual_scratch_um <= scratch_limit
    and predicted_clearcoat_remaining_um >= clearcoat_safety_limit
    and healthy_area_overremoval_um <= overremoval_limit
    and force_peak_n <= region_force_hard_limit_n
    and no_collision
)
```

각 수치의 근거 태그와 config 경로를 평가 JSON에 저장한다.

## 4. 역할 분리

| 구성요소 | 담당 역할 |
|---|---|
| Isaac Sim/PhysX | 로봇, 관절, 충돌, 패드 접촉, 장면 |
| RMPFlow/기준 제어기 | 경로 추종, 표면 접근, 기본 자세·힘 제어 |
| PPO 잔차 정책 | 곡률과 상태에 따른 힘·속도·자세 보정 |
| 표면상태 전이모델 | 위치별 제거·Scratch·Roughness·Clearcoat 변화 |
| GU proxy 모델 | 논문 앵커를 이용해 표면 품질을 20° GU 척도로 변환 |
| RTX 측정 | 20° 정반사 형상과 결함 반사 시각화 |
| BO | 디지털 트윈에서 공정 레시피 탐색 |
| 안전 계층 | 과압, 관통, 충돌, 과다 제거, 도막 안전한계 처리 |

## 5. 데이터의 의미

강화학습 실행으로 생기는 데이터는 두 종류다.

### PhysX/제어 시뮬레이션 데이터

```text
joint state
TCP pose/velocity
contact force
path error
surface normal
curvature
dwell/pass/coverage
```

### 논문 기반 품질 시뮬레이션 데이터

```text
predicted removal
predicted Ra/Rz
predicted scratch improvement
predicted remaining clearcoat
predicted 20° GU proxy
```

두 종류 모두 디지털 트윈 내부 데이터다. 실제 시편 계측 데이터와 합치거나 혼동하지 않는다.

## 6. 고정 전제와 에피소드 랜덤화

### 고정

- 패드 직경·재질·접촉면 형상
- 선택된 compound profile
- 표면상태 모델 버전
- GU proxy 모델 버전
- 단위계와 좌표계

### 에피소드별 랜덤화

- 표면 family와 주곡률 `k1`, `k2`
- 표면 방향과 위치
- 초기 Ra/Rz와 Scratch 분포
- 초기 Clearcoat 두께
- 목표 힘·Feed·RPM·Step-over recipe
- 경로 방향·시작점·패턴
- 접촉강성·마찰·센서 노이즈·지연

## 7. 금지사항

- 논문에 없는 값을 논문 직접값이라고 표시하지 않는다.
- `predicted_20deg_gu_literature_proxy`를 Gloss Meter 측정값이라고 표시하지 않는다.
- Lux를 GU로 직접 변환하지 않는다.
- OPM과 RPM을 같은 물리량으로 처리하지 않는다.
- 서로 다른 재료의 논문 결과를 단위 설명 없이 하나의 직접식으로 합치지 않는다.
- PPO가 안전 계층을 무시하는 최종 로봇 명령을 직접 내게 하지 않는다.
- 특정 자동차의 절대 좌표를 일반화 정책의 핵심 관측으로 사용하지 않는다.
