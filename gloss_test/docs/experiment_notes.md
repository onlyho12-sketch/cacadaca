# 실험 메모

## 20°가 유지되는 방식

20°는 월드 좌표축 기준이 아니라 측정점의 표면 법선 `n` 기준이다. 접평면에서
한 방향 `t`를 정하면 광원과 검출기의 중심 방향은 각각 다음과 같다.

```text
l = cos(20°) n + sin(20°) t
v = cos(20°) n - sin(20°) t
```

따라서 표면 법선이 +X 또는 +Y여도 같은 식으로 장비 전체가 회전한다.

## 곡면

곡면 전체에 단일 광원/카메라를 고정하면 모든 픽셀이 동시에 20°가 될 수 없다.
가상 gloss meter는 측정점마다 위치와 법선을 구한 후 작은 국소 영역을 평면으로
근사하고 장비를 재배치한다. 곡률 반경에 비해 측정 spot이 충분히 작아야 한다.

## 빛의 퍼짐

광원의 중심축이 20°이고 Rect Light의 유한 크기가 조명 개구를 만든다. 검출기 쪽은
카메라의 시야와 중앙 ROI가 수광 개구 역할을 한다. Clearcoat roughness가 커질수록
정반사 lobe가 퍼지며, 중앙 수광 범위에 들어오는 에너지가 줄어드는지를 측정한다.
현재 구현은 ISO 2813 장비의 정확한 aperture를 복제한 것이 아니므로 GU라고 부르지 않는다.
